# NimbusXR Homebrew tap

Homebrew casks for NimbusXR tools.

```sh
brew install nimbusxr/tap/axx
```

| Cask | |
| --- | --- |
| `axx` | [axx](https://github.com/nimbusxr/axx), the human-readable acceptance testing framework for the agentic era |

The casks are written by the tools' release workflows; don't edit them by hand.
